# DSJ-4-Wind-Unlocker  
DSJ 4 Wind Unlocker to skrypt, który odblokowuje ograniczenie wiatru w grze DSJ 4 na wyższe wartości.  
Wydano następujące wersje:  
# Wind Unlocker 1.0
-działanie dla wersji DSJ 4 1.11.3  
-odblokowuje ograniczenie wiatru w zakresie -25.0m/s-25.0ms/s  
-działanie tylko dla trybu PŚ  
# Wind Unlocker 1.1
-działanie dla wersji DSJ 4 1.12.2    
-odblokowuje ograniczenie wiatru w zakresie -50.0m/s-50.0ms/s    
-działanie dla trybu Zawody  
-możliwość stosowania z programem WindPoints(z wyłączonymi loteryjnymi warunkami)
